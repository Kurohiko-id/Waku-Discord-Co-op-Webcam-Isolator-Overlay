Persiapan sebelum live

Di Discord

  • Matikan Show Non-Video Participants (Tampilkan peserta tanpa video), supaya grid hanya berisi tile kamera.
  • Bagusnya klik kanan kamera kamu sendiri, lalu hilangkan centang Show My Own Camera.
  • Jangan ganti tema atau ukuran jendela Discord saat live; crop dan kotak deteksi bisa meleset.
  • Perhatikan Streamer Mode, karena bisa mengubah posisi overlay Discord.

Capture dan OBS

  • Klik Capture, lalu pilih jendela Discord (bertanda Discord). Jangan di-minimize (capture beku); boleh tertutup jendela lain.
  • Di OBS tambahkan Browser Source 1920x1080 dengan alamat preview di bar atas (tombol salin di sebelahnya).
  • Bitrate dan FPS diatur di tab Atur; angka yang benar-benar terkirim ke OBS tampil di sana.

Frame

  • Tambah frame: atur kotak crop pas di area kamera orangnya, lalu Simpan. Ikon pensil di tile untuk mengedit lagi.
  • Virtual frame: frame dari gambar (PNG, JPG, GIF, WebP), tanpa capture. Gambarnya bisa digeser dan di-zoom, dengan latar warna atau transparan.
  • Di kanvas: tarik tile untuk memindah, tarik sudutnya untuk ubah ukuran. Tahan Alt sambil menarik sudut atau sisi untuk memotong (crop) tanpa mengubah skala gambar.
  • Pilih beberapa tile sekaligus: Ctrl+klik, atau tarik kotak dari area kosong kanvas. Tile terpilih bergeser bersama; Esc atau klik area kosong untuk batal.
  • Tombol kiri atas tile mengembalikan crop dan ukurannya; tempat sampah menghapus (klik dua kali). Ctrl+Z / Ctrl+Y untuk urungkan dan ulangi.

Deteksi bicara

  • Paling akurat: pakai API resmi Discord. Status bicara diambil langsung dari aplikasi Discord di PC ini, jadi tidak terganggu warna baju atau latar. Isi Client ID dan Client Secret sekali saja: .
  • Deteksi bicara diatur per frame di popup edit frame. Frame baru mulai Nonaktif.
  • Official: setelah Discord tersambung (pill Discord di bar atas), pilih akun orangnya di voice Discord. Frame virtual hanya bisa lewat cara ini.
  • Manual: geser kotak hijau (kotak deteksi) ke tempat outline hijau Discord muncul. Saat orang itu bicara, angka Hijau terbaca harus naik dan kotaknya menyala.
  • Kalau Hijau terbaca tinggi saat orang diam (baju, latar, atau green screen), geser kotaknya atau naikkan ambang di tab Deteksi.

Preset

  • Simpan susunan sekarang di tab Preset; tombol preset di bawah kanvas menerapkannya dalam satu klik.
  • Preset yang disematkan (ikon pin) tampil sebagai tombol di bawah kanvas; sisanya di menu Lainnya. Tarik tombol atau baris preset untuk mengubah urutan.
  • Centang Simpan juga nama frame & akun Discord untuk teman mabar tetap. Tanpa centang, preset hanya menyimpan susunan.
  • Jadikan ukuran utama membuat semua frame persis seukuran frame terpilih.

Discord Deteksi Suara

Opsional. Dengan API resmi dari Discord, Waku bisa memakai fitur pendeteksi suara yang akurat. Aman, karena fitur ini memang disediakan resmi oleh Discord.

  1. Buka Discord Developer Portal, klik New Application, lalu beri nama aplikasinya. Nama tidak boleh mengandung kata "discord".
  2. Klik menu OAuth2. Copy Client ID dan masukkan ke kolom Client ID di bawah.
  3. Klik Reset Secret > Yes, do it!, copy Client Secret, lalu masukkan ke kolom Client Secret.
  4. Masih di halaman yang sama, di bagian Redirects klik Add Redirect, ketik http://localhost, lalu klik Save Changes.

Secret hanya disimpan di PC ini dan tidak pernah ditampilkan lagi.

Shortcut
